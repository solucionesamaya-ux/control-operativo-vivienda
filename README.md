# Control operativo · Secretaría de Vivienda

Página de entrada del panel de seguimiento contractual de la Secretaría de Hábitat y Vivienda Social (Gobernación de Cundinamarca).
Solo contiene el logotipo, los íconos para la pantalla de inicio y un botón que abre el panel (Google Apps Script) con el enlace personal de cada persona.
No contiene datos de contratos ni de personas.
